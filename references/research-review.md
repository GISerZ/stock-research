# 前瞻登记与研究质量复盘

在新完整报告发布时登记关键预期，或在用户要求复盘／已登记窗口到来时读取本参考。普通短答不强制建立完整记录。只评价有原判断和精确版本可查的事项；研究质量、预测兑现、行情表现和真实执行分别记录，不做自动回测、排名或参数优化。

## 发布时固定原判断

- 从已采用的`final_decision`及其事实／假设中，选最影响结论的三项经营／事件预期和一个主要失败路径。每项用`E1 / E2 / E3 / F1`等稳定ID；不足三项时说明缺口，不为未评级或限制性报告捏造预测。不要罗列全部财务指标，也不把未采纳情景变成原预测。
- 固定精确报告、底稿版本、`final_decision.id`和相关输入／假设／结果ID。没有契约底稿时定位实际计算稿／最终章节，缺失写明；不重建旧底稿。区分已核起点、研究假设、条件情景和失败路径，定量预期注明数值或范围、单位、主体／归属与期间，定性事件注明可观察判据；模型空间不称为预期收益。
- 分列实际研究截止、报告发布时间和登记时间，保留真实精度及时区，未知写未知及影响。采用来源保留当时可获得时间及精确原件／页码；不能只用报告期或网页今天的更新时间证明当时已公开。若发布后才补登、结果已可知或登记时点无法确认，标`补登／回顾，非前瞻样本`；不回填今天的资料为旧共识。
- 发布时预先约定观察来源、到期日期或事件窗口、支持／反证判据、失效条件及下一动作；事件无确定日期时给最迟复核日。默认基本面期限为估值日起未来12个日历月，固定明确起止、中期检查和期末复评；用户指定其他周期及历史原窗口按实际保留。经营兑现期与披露可获得期分开，不能因披露尚未发布就判预测失败。短期情绪如有原登记，引用原叙事附件、原短期窗口和判据，单列于基本面期限之外，不以短期涨跌裁决一年期判断。
- 登记报告实际采用的期末情景及精确结果ID、盈利／倍数口径和期间决定性节点，与财年经营预期分开。按既有E类条目或其关联说明保存，不为期末情景另造概率或一套预期编号。期末价格判断在原终点评估，终点后的年度披露继续核验原经营预期，不能移动原价格窗口；没有可支持的期末数值时保留缺口，不补造旧预测。
- 不为了改善结果移动窗口、改阈值或换样本。新事实／新模型导致修订时保留原登记及原窗口，为新报告另建登记并互链；窗口结束后的披露延迟记待补证据，不能伪装成原窗口仍未到期。失败、未评级、条件未触发、失效和被新报告替代的条目均保留。

## 保存与台账

每项在现有“当时依据”或关联说明中写：`原预期：精确thesis-review附件＋E/F ID；关系：首次/沿用/实质修订；变化：具体内容`。本报告E1本身不能识别前份报告E1；首次写“无前项”，未知旧关联写未知及影响，不倒造编号或重建旧预测。仅报价更新、格式/登记时间更正且经营假设与原窗口不变属于沿用，不新增独立经营预期；收入、利润率、倍数、主体或窗口等实质变化逐项写旧值→新值及理由，保留原条目/窗口并互链。新报告版本数与独立预期数分开。

未来汇总须分别说明报告数、去重独立预期数、关联更新/修订数和已到期且有同口径证据的可评价项，给出纳入/排除理由及缺证据数；不能把所有登记行作胜率分母。未到期不算成功，到期缺披露、失效、条件未触发、未评级、失败及无法判断分别保留；关联修订不当作多个独立成功样本。当前只定义记录方法，不开发收益统计、自动评价或调参。

首次附件保存为当前工作区`research/evidence/manual/YYYY-MM-DD-CODE/thesis-review.md`；后续登记修订或复核另存同目录`thesis-review-v2.md`、`thesis-review-v3.md`等，不覆盖任何已存版本。报告日期目录用于归档，不代表已在当时登记；附件内的实际时间才是依据。新版写明精确前版、原登记版本、变更范围和原因，保留原始登记字段，复核事实放在单独区块，不改成原先已知。

报告在发布时链接实际保存的附件版本；后续复核由台账链接新版，不回写旧报告让它看似引用过未来资料。附件内路径相对自身目录解析，用`/`及精确文件名，并给JSON Pointer／章节／PDF页定位。底稿ID须连同精确底稿版本引用，单独一个ID不能识别原决定。

当前工作区入口为`docs/stock-research/review-ledger.md`（若存在，先读其格式）；没有时，在用户已授权的保存范围内建立同类轻量索引。每行对应“精确报告版本＋预期ID”，列原登记及最新复核附件、窗口、状态和下一动作。新增或更新时保留失败及未触发条目，不只选上涨或获评级样本。路径相对台账目录解析。台账与本附件均不作为单股报告计数，不修改`research/股票研究总览.md`来登记复盘。

## 复核与归因

先对照原条目及预先约定窗口，再核验届时公开的原始披露和时间。状态用`未到观察窗口 / 到期待复核 / 已复核 / 已失效 / 无法判断`，与“支持／未兑现／反证／条件未触发”等结果分列。到期缺披露或旧引用不可读时说明原因，不能写成通过或失败；条件未触发不是已成交，未评级也不是失败记录可被删除的理由。

| 偏差类别 | 应核清的区别 |
|---|---|
| 事实／单位归属错误 | 当时原文、单位、期间、主体、会计归属或实际股本是否被误读；后续更正与当时研究错误分开，保留两版披露及可获得时间 |
| 计算错误 | 从原采用输入到结果的公式／转换是否有误；与输入变化和预测落差分开 |
| 经营假设偏差 | 当时有据的量价、利润率、归母／现金或事件假设为何未兑现，实际结果与原假设是否同口径 |
| 倍数变化 | 经营兑现与估值倍数重定价分开；没有可比依据不把全部涨跌归给倍数 |
| 信息延迟 | 事件发生、首次公开、采集、核验与采用分别何时，是否已有公开材料却未及时更新 |
| 条件传递错误 | 报告、计划或总览是否丢失必要条件、等号、观察状态、报价时点或继承边界，导致原条件被错误激活 |
| 账户约束不匹配 | 仅依据用户实际提供的期限、资金、持仓、成交及限制判断；未知则无法判断，不从评级推定个人盈亏 |
| 正常不确定性 | 当时有据且明确披露的风险与范围；不能用此标签掩盖可核的事实或计算错误 |
| 仍无法判断 | 多重因素、缺证据或口径不可比时保留未知及下一核查点，不强分摊归因比例 |

同一项可有多个有据原因，逐项说明影响环节，不为完整性凑分类。原输入或计算错误可在发现时立即复核，无需等长期窗口；经营预期和收益效果须等各自窗口或原定决定性事件，不能提前宣称默认一年期效果已证实。

行情表现单列，不能替代事实正确性或预测兑现。比较前明确研究情景、证券价格表现还是真实执行，记录相同起止窗口和可比市场／行业基准的精确数据版本；原来没有约定而事后增加的比较要标明。发布时若约定期末行情比较，同时注明参考报价时点、终点取价及非交易日对齐方法；交易日对齐不改变原研究终日，停牌／缺价保留限制。两端价格须同币种、同单位及一致复权基准，除权／分红时说明调整因子或事件；未复权价差不等于总回报，股息和再投资假设另列。基准或数据不可比就披露缺口，不强算超额表现。

没有真实成交和账户约束就仅讨论研究情景或行情比较，不声称策略成交收益、个人盈亏或模拟成交；即使进入过观察区也不等于触发全部条件。用户明确提供实际执行且要求复核时，才按实际数量、时点、费用、分红及交易／流动性约束另行核对，不能把模型空间当作实得或概率加权预期收益。

## 重大新事实回到跟踪流程

发现改变结论的事实、股本、模型或失效事件时立即按[follow-up-workflow.md](follow-up-workflow.md#五类变化与重做范围)分类处理，定位受影响输入／结果、旧条件及下一动作；不必等原复盘日。受影响结果与最终条件另存新底稿／报告，按现有审查及总览规则交付；未完成时保留待办及失效范围，不重新激活旧条件。

复盘附件只记录观察、归因和转交，不直接修改评级、价带、研究截止或原观察窗口。规则／流程缺陷记为可改进动作，不自动改Skill或启动训练。默认长期评价尚未到期时只交付记录方法和已到期事项；不据此生成收益排行榜、回测、自动调参或定时任务。
