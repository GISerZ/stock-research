# 研究结论交换字段约定（设计契约，尚未导出）

本文件只定义未来对接其他项目时的最小 JSON 语义。本轮没有 JSON 写入器、消费端或服务接入；报告 Markdown 和证据包仍是当前产物。等确定消费项目、字段用途和版本兼容规则后再实现导出。

## 字段

| 字段 | 约定 |
| --- | --- |
| `schema_version` | 整数 `1`。结构变化时升版。 |
| `target` | 六位 `code` 与明确的 `exchange`（`SH`、`SZ`、`BJ`）；板块和简称为可选信息。 |
| `research_as_of` | 带时区的研究资料截止时间；与文件创建时间、报价时间分别记录。 |
| `report_path`、`evidence_paths` | 已完成报告及本次实际使用的核心 JSON、个股情绪和各市场日快照的精确路径／版本；缺少的路径为 `null`，不得猜测最新文件。 |
| `quote` | 未复权人民币元／股现价、供应商原始链接、供应商交易时间、交易阶段、抓取时间、核验状态。缺失时值为 `null`。 |
| `filing_verification`、`share_basis` | 最新重大披露的原文 URL、公告日期、核验状态；总股本数值、口径、截至日期及原文。未知项目为 `null` 或明确缺口，不伪称已核。 |
| `rating`、`no_rating_reason` | 本 skill 的 `买入 / 增持 / 持有 / 减持 / 回避` 之一；未满足门槛时 `rating=null`，`no_rating_reason` 写 `数据不足，暂不评级` 的具体原因。 |
| `holding_horizon` | 评级或情景适用期限，写起止或可核验的期限描述；无评级时可为 `null`。 |
| `valuation` | 方法、已核财务基数及期间、低／基准／高情景假设与每股价值、公式、安全边际；区分事实与模型推断。 |
| `bands` | `buy`、`hold` 的人民币元／股区间，及减持／重估价位或事件。无评级时 `buy=null`、`hold=null`；`减持 / 回避` 时 `buy=null`、`hold=null` 且语义为“暂不买入”，不伪造持有区间。 |
| `invalidation_triggers` | 使评级或区间必须重算的披露、股本、经营、估值或期限事件。 |
| `agents_run` | `complete / partial / not_run`，记录实际参与角色和缺失回合；不能把模拟角色当成独立 Agent。 |
| `source_urls` | 支撑关键事实与估值输入的原始 URL，保留事实类别、发布时间和核验状态。 |

## 不变量与外部映射

`rating=null` 时 `bands.buy` 和 `bands.hold` 必须为 `null`，不能从上一份报告或别的项目补入。缺少最新重大披露、明确股本口径或带时间戳现价时仍按本 skill 的未评级门槛处理。保存原文来源和快照路径，便于消费端回查；交换记录本身不使未核数字变成事实。

跨项目代码先还原为六位代码和交易所：本 skill 常用 `sh/sz/bj`，有的项目用 `600519.SS`、`000001.SZ`。`.SS` 与 `.SZ` 可在明确交易所后映射；北交所没有通用的相同后缀约定，须显式保留 `BJ`。其他项目的“强烈买入／卖出”等评级不自动映射为本 skill 的五档评级。外部单一目标价、止损价和 Agent 评分只作为带原词、来源、时间的**外部观点**，不能直接成为本 skill 的买入／持有区间或已核官方事实。

交换端须分别标记 `官方披露`、`市场数据`、`模型推断`、`外部应用观点`。只有本 skill 在原文核验和评级门槛满足后形成的结论，才可填其自身 `rating` 和 `bands`。
