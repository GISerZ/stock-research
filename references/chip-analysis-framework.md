# 筹码分布与成本估算

每次个股分析都执行独立筹码采集，并保留明确的“筹码峰与成本分布”专节，覆盖完整深研、跟踪更新及简短判断；短答可压缩为一段，不因此扩展为完整深研。筹码峰、成本分布或“主力成本”专题也可单独调用。只覆盖沪深 A 股，北交所输出 `not_supported`。该附件补充市场成本结构，不替代已核披露、经营/估值模型或当前报价。

## 采集和读取

```powershell
$stockSkill = Join-Path $env:USERPROFILE '.codex\skills\stock-research'
python (Join-Path $stockSkill 'scripts\collect_chips.py') --code 600519 --output-dir .
```

使用已有且装有所需固定依赖的 Python；`.venv` 的解释器可能已失效。输出文件为 `research/evidence/chips/采集日-CODE[-vN].json`，日期是北京时间采集日，不一定是数据日。必须读实际返回的精确版本，不能猜最新文件名。

- `collection_status=complete`：当前预期完整日的本地结果达到输入/模型覆盖规则；不表示模型是真实账户成本或投资判断可靠。
- `partial`：短历史、初始化残留较大、换手限制、过期结果、仅供应商摘要或图表缺失；逐项读 `issues`。
- `failed`：没有可用结果，仍尽可能保存来源诊断；`not_supported` 表示市场覆盖边界。
- `data_mode=local_distribution`：有分布、本地成本指标和可选图；`vendor_summary`：仅供应商摘要；`unavailable`：没有筹码数值。
- 退出码 0=完整本地结果，1=部分结果或不支持，2=来源/日历/依赖/参数/保存失败。非零不要求重跑其他研究采集器或对来源反复重启。

盘中只取前一个已结束交易日；非交易日用最近完整交易日。日历失败不猜测周一到周五。收盘后上游尚未发布时使用实际旧日并标 stale，不能把昨日筹码称作今日筹码。

## 数据来源和基准

主源 `baostock_chip_history` 在独立 SDK 进程内查询最多五年日线及末日未复权四价，整个进程上限 45 秒。价格单位元/股，成交量股，金额元，换手率原始单位百分数。模型选最近 500 个有成交日及窗口起点至末日之间的停牌/零成交行。

先保存供应商前复权 OHLC，再用 `scale=末日未复权收盘/末日前复权收盘` 统一换算至末日价格基准；末日四价校准误差上限 0.01 元。量、额、换手率不乘此比例。快照冻结原始输入、变换后输入、锚点与参数，不以后来重算的复权序列替换历史附件。只支持当前可得完整日，不作历史时点回测。

主源失败或过期时按定义尝试 `akshare_chip_summary`（`stock_cyq_em(adjust="")`）。它只有近 90 日摘要，没有逐价位分布；摘要日期比可用本地历史严格更新才替换本地模式。一个快照只选一种结果，保留未选来源的状态、实际日期和失败链。

AKShare 固定版本 1.18.97 的“平均成本”实际是 P50，保存在 `vendor_summary.reported_avg_cost`，方法为 `median_p50`；版本未经重新核对时是 `vendor_label_unverified`。不将它填成 `weighted_avg_cost`。摘要未复权算法与本地基准不同，不拼接两个来源计算成本迁移。Tushare 尚未接入，不能暗自调用付费权限或补成真实持仓。

摘要先检查日期顺序/未来日期，再在已完成候选中选择最新有效行；数值无效的历史行跳过并在来源 `coverage.skipped_invalid_rows` 中保留日期/原因，不能让旧坏行挡住合法末日。若较新行无效，只能展示所选旧日并标 stale，不能伪装成当天摘要。

## 模型及指标

算法版本 `triangular-turnover-v1`。每个成交日在低价 L、高价 H、中心 `(O+H+L+C)/4` 间采用三角分布，按 CDF 差计算各价格档概率。一字价是所属档的点质量；停牌不更新。首个有成交日假定为初始分布，其后按 `D_t=(1-u)D_(t-1)+u*T_t` 更新，`u=min(换手率/100,1)`。

有效成交日少于 120，或自第二个有效日起的 `product(1-u)>5%`，记 partial；这些是质量默认值，不是统计置信度。换手大于 100% 的截断日期、正成交但零换手、正常交易缺换手分别记录或拒绝，不能推断缺失值为零。

BaoStock 明确返回 `tradestatus=0` 时，空成交量/成交额按停牌零成交规范化，空换手保留为缺值；仍检查没有非零成交/换手，保留该日期且不更新筹码。正常交易行的空量额或换手继续拒绝，数值解析错误记录日期、字段和原值，不将一般缺失值当零。

固定网格最多 400 个等宽箱，非单点档宽不小于 0.01 元；代表价为箱中点。全历史单一价时用原始点价。单点归箱存在最多半个箱宽的价格量化误差，须披露实际 `bin_width`。分布是剩余成本的模型估计，不是累计成交量直方图。

| 字段 | 含义 |
| --- | --- |
| `metrics.reference_price` | 实际数据日未复权收盘，不是盘中当前报价 |
| `weighted_avg_cost` | 各档代表价按概率加权的均成本 |
| `median_cost` | 累计概率达到 50% 的档代表价 |
| `main_peak_price`, `main_peak_tied` | 最大权重档；绝对差不超过 1e-12 视为并列，取低价档并披露 |
| `cost_70_low/high` | Q15—Q85 |
| `cost_90_low/high` | Q5—Q95 |
| `concentration_70/90` | `(上界-下界)/(上界+下界)`；越小表示成本区间越窄 |
| `profit_ratio` | 参考收盘价及以下档代表价的概率和，含平价、忽略税费 |
| `price_vs_weighted_avg_cost` | `参考收盘价/加权均成本-1`，不是安全边际或主力净盈率 |

概率和容差 1e-8，只有浮点尾差可归一化。字段内部比例为 0—1，显示成百分比一次，不重复乘/除 100。显示四舍五入不能反过来替代计算值。供应商换手口径、有限历史和初始状态、复权方法、增发/解禁改变持仓群体、税费及资金身份不可观察均属于限制。

## 报告、Agent 与跟踪

报告头部写精确筹码快照及采集时刻；第 7 节用表格展示实际数据日、模式、成本/主峰/区间/集中度/获利比例、模型限制，并引用 JSON 中真实 `chart_path`。从 `research/` 引用时去掉 chart_path 开头的 `research/`。SVG 带“模型估算”、坐标与图例；不能画图的阅读环境保留表格和图链接。

报告实际链接的每张筹码 SVG 必须属于报告已引用且有效的某个筹码快照。跟踪对照要显示旧图时同时引用其精确旧快照，不能只换新 JSON 而继续贴旧图；图的哈希和路径校验不代替这项关联检查。

仅摘要时只展示供应商字段，明确缺主峰、加权均成本和分布图；无数据时说明一次原因，不把 null 写成零或重复填满无数据表格。合法故障附件可以作为缺口证据引用，不是有效筹码结果；图表缺失也不等于核心财务证据失效。

### 必有内容与滞后分布补充

有本地分布时，专节须解释主峰价、分布支持的峰形／成本密集区、上方潜在套牢区与下方历史成本区，并列出均成本、70%／90%区间、集中度及模型获利比例；这些区域只表示估算成本结构，不认证支撑／阻力。与当前报价比较前核对实际数据日和价格基准；跟踪时只在来源、算法、窗口、复权及分箱可比的范围内解释峰位变化，不只贴指标表或图片。

当最新结果为 `vendor_summary` 或 `unavailable`，主动查找已保存且可读的最近一份 `local_distribution` 快照及其真实图表，不因摘要日期更新就省略可用的历史筹码峰。分成“最新成本摘要”和“最近可用历史筹码峰”展示，分别引用精确 JSON、采集时点、实际数据日和方法；历史分布相对本次已滞后须明示，原快照的 `complete` 仅描述当时采集质量。历史图只作背景，不能称作最新分布、据此认定当前峰位／支撑／压力或与不同方法的摘要计算迁移。不存在可用历史分布时，专节写明“筹码峰数据不足”、主备源实际状态及恢复有效分布的条件，不能用 P50 代替主峰，不能补造分布或重算历史附件。

所有独立角色读相同冻结版本、数据日、算法版本、模式和限制，筹码推断与官方事实分开。重要补充和异议分类沿用 `multi-agent-debate.md`，不新增角色或为追求一致重跑。跟踪按 `follow-up-workflow.md` 定位前次实际引用；来源/算法/窗口/复权/分箱不可比时不给迁移百分比，无旧附件不倒填。

## 对研究判断的边界

沿用 `position-building-and-risk.md` 的评级、定性置信度、新资金状态与硬约束，以及 `valuation-framework.md` 的经营/估值模型和价带：

- 低于均成本、筹码集中或出现主峰不等于便宜、可买或主力吸筹；高于成本也不是必然卖点。
- `complete/partial/failed` 不映射为评级、置信度或新资金状态；筹码缺失通常是辅助缺口，不自动要求暂不评级/仅观察。
- 经营/估值未完成仍如实标研究未完成，不能借筹码图生成价带；可界定的未来分歧进入情景/敏感性，不等所有技术指标转好才评级。
- 把技术条件设为必要入场条件时，说明证据、实质影响、解除条件与等待理由；买入/增持仍须当前报价处于有效买入区且必要条件已满足。
- 筹码上移不能豁免价格上限；先重估并替换唯一最终价带，才能讨论超旧区间参与。不重复折价同一风险。
- 采集器不生成评级/主力身份/价带/统计置信度；“主力成本”提问应明确这里只能提供筹码成本估计。

## 人工验收

由用户按实施方案的人工清单验收；禁止自动验证的工作区不运行报告验证器、编译、测试、自检或 fixture 回放，也不新增测试用例。生产保存边界的字段/概率检查不表示回归或投资效果经过验证。
