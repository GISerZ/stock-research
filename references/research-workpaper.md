# 研究底稿契约（workpaper_version = 1）

深研、估值或正式评级使用本契约记录本次采用的事实、假设、计算及最终条件。沿用现有人工计算方式；这里只统一外层，不提供计算器、评级生成器或核心证据包。评级门槛及价带语义仍见[估值规则](valuation-framework.md)和[评级与风险规则](position-building-and-risk.md)。

## 保存与兼容

- 新研究保存为当前工作区的`research/evidence/manual/YYYY-MM-DD-CODE/workpaper.json`；同日更新另存`workpaper-v2.json`、`workpaper-v3.json`等，不覆盖已有版本。文件名版本表示同日修订，`workpaper_version`表示字段契约版本，两者独立。
- 报告、简报或其他底稿只引用实际保存的精确版本。`basis.supersedes`说明被替代文件、定位、范围和原因；替代最终条件不等于旧事实、模型或审查全部作废。
- 底稿中的本地`path`相对**本底稿所在目录**解析，用`/`分隔；报告中的链接相对报告目录解析，不能原样抄路径。`locator`定位JSON Pointer、Markdown章节或PDF页码/表名；PDF页码注明文件页码或印刷页码。原始网页用直达`url`。
- 不迁移、重写历史报告和计算稿。复用旧附件时保留其单位、原截止及原核验记录；新底稿记录本次采用判断。仅整理历史结构时，明确“非本次重新核验/当前评级”。
- 本辅助文件用`kind=research_workpaper`、`workpaper_version=1`，**不使用`schema_version`，不添加`source_results`，文件名不用核心包的日期代码命名**。它不能替代核心采集包、原文或带时间戳报价；保存成功不代表核验或验收通过。

## 共同外层

以下顶层字段固定保留。没有适用条目时数组为`[]`；未知值为`null`并说明原因，不能用零、空字符串或估算事实填洞。

| 字段 | 最小内容 |
|---|---|
| `kind` | 固定字符串`research_workpaper` |
| `workpaper_version` | 整数`1` |
| `target` | `code`六位字符串、`name`、`exchange`；不丢前导零 |
| `basis` | `research_as_of`、`valuation_date`、`valuation_fiscal_year`、`holding_horizon`、`reference_quote_ref`、`model_status`、`report_ref`、`evidence_refs`、`supersedes` |
| `verified_inputs` | 输入记录数组；每条标明真实核验状态及本次是否采用，名称本身不赋予verified状态 |
| `assumptions` | 假设数组；与事实分开，保留数值、依据、适用期间和口径 |
| `derived` | 一次计算的结果数组，保存公式说明及输入/假设引用 |
| `scenarios` | 低/基准/高等情景，引用驱动、分母及已保存结果 |
| `sensitivity` | 决定性分歧的变化范围、结果及对判断的影响 |
| `final_decision` | 本次已采纳决定；未知或未评级仍保留对象和原因，价带按规则置null |

`research_as_of`用带时区的ISO 8601时间，无法精确到秒时保留真实精度，不杜撰时间。`holding_horizon`采用下节的新底稿写法；历史字符串或旧对象保留原样，不为新默认迁移。`reference_quote_ref`引用报价输入ID，不能只写一个无时间的价格。`model_status`取`not_started / in_progress / completed`，与能否评级分开。`report_ref`、`evidence_refs`引用精确文件及定位；尚无报告时`report_ref=null`并在`basis.note`说明。`supersedes`无前版时为null，否则记录`path / locator / scope / reason`，定位被替代的最终决定或旧报告章节。

### 研究期限与期末情景

新底稿的`basis.holding_horizon`使用对象：`type`为`研究假设`或`用户指定`，`months`为明确的整数月数（继承的期限区间或非按月期限为null，并在`note`保留原描述），`start / end`为`YYYY-MM-DD`，`note`说明继承、指定期限或其他必要口径。首次建立或明确重置默认前瞻窗口时，`months=12`、`start=valuation_date`、`end`为12个日历月后同日；目标月无同日时取该月末日。例如2026-11-06至2027-11-06，六个月后可作检查点，不是研究起点。继承更新保留可核的原起止；原日期不明确时留null及原因，不能从今天重置。默认周期不是用户资金期限；用户指定其他周期时采用实际起止日期。

`valuation_fiscal_year`单列盈利财年，不由终点年份机械推定。期末估值的盈利口径、倍数及其为何可能在终点获得定价，记录于现有`assumptions`；低/基准/高情景的模型价值、可支持的期末价格和相对参考报价涨跌幅，在`derived`计算一次并由`scenarios`引用。每项记录保留适用时点/期间；模型价值与期末价格相同时，也须说明采用同值的兑现依据，不能只改标签。不另增一套顶层模型或默认情景概率；无法支持的期末数值保留null及原因，按现有未评级原因判断其是否构成决定性建模缺口。

期间关键节点及默认一年期的六个月中期检查、期末复评要求记录于`final_decision.watch_items / invalidation_events / next_update`等现有字段，注明经营发生期、可获得披露期及判据；其他期限按实际窗口选择检查点。短期情绪另列原窗口，不生成每月价格预测。终点后的年度披露只用于后续核验经营假设，不能延长原价格判断窗口。

## 从输入到最终报告

新研究按以下顺序形成同一次决定，字段不分散另立定义：

1. 核验决定性原件、实际股本及带供应商时间的报价，在`verified_inputs`记录核验与本次采用；候选、缺失、冲突不作已核数值。
2. 用`assumptions`解释经营、归属、估值驱动及适用财年/期限，事实与预测分开。
3. 在`derived`计算一次转换、桥接、每股价值及边界；`scenarios`引用结果，不另算一份。保留精度及显示舍入说明。
4. 在`sensitivity`处理决定性且有据的分歧，说明风险已计入盈利、倍数或折价的哪个位置，以及现价判断是否改变。
5. 待审方案引用精确底稿版本和提议采用的结果ID，仍标为提议。主研究者完成适用审查及裁决后，将已采纳条件写入`final_decision`；不因缺失角色或未采纳提议而虚填审查完成。
6. 报告头部链接该精确底稿版本及最终决定ID；核心结论表达同一决定，估值、多空、风控和后续计划复用已算结果。交付前人工对齐；发现冲突先修订并另存版本，不能把两个不一致的方案同时作为有效结论。

`final_decision`是已采纳条件的结构化来源，报告核心结论仍是面向读者的权威表达；两者表达同一决定。最终采用尚未确定时保留对象、未知项为null并说明待裁决，不把待审方案填成已采纳决定；旧结论只在其明确继承范围内有效。

## 更新与继承范围

跟踪先按[follow-up-workflow.md](follow-up-workflow.md#五类变化与重做范围)标记事实／股本事件、仅报价、模型假设、辅助补件或关键旧引用缺失，可逐项并列。下表保留已有计算处理；事实与模型分别记录变化来源，辅助补件包含筹码、消息及情绪。发现事实、财年、期限或假设变化时，不能仍标作“只变报价”或“只补件”。

| 更新 | 重新核验/计算 | 可以继承及必须重看 |
|---|---|---|
| 基准输入或模型改变 | 核验并采用变更项；沿引用链重算受影响的单位转换、归属/现金/股本桥接、情景、敏感性、价带及报价相关指标 | 未受影响输入/结果可保留，列明精确版本与范围；重看评级、新资金状态、必要条件、失效事件和旧方案替代范围，不重复计入同一风险折价 |
| 只变报价 | 核验新未复权报价、供应商时间及原始响应；为新交易时点建立报价ID，同步`basis / final_decision`的`reference_quote_ref`，重算安全边际、价格空间、溢折价和适用的反向估值等报价相关结果 | 无新事件且原期限/模型仍适用时可继承经营假设、情景值和价带；须重新判定带内关系、评级与新资金状态，不能因涨跌机械移动价带，也不自动顺延旧复核日 |
| 只补筹码／消息／情绪 | 引用实际附件版本、可获得／采集／审阅时点及适用的数据日、模式和缺口；仅更新辅助解释，不因成本峰、缺失或模式变化重算基本面模型 | 事实、模型及最终条件明确继承原精确版本和截止；不把旧报价写成新现价，不宣称旧审查已覆盖补件。若要发布新的当前评级仍须满足当前事实/报价门槛；新核实的决定性经营或风险事实转入第一类处理 |

补件在`basis.note`或其说明中列明继承的精确底稿/报告、输入和结果ID、原截止及未完成核查。受影响的派生数和最终决定必须引用本次采用的结果；旧文件仅作为历史/继承依据，未采纳旧边界不能进入当前执行口径。无决定变更的纯筹码补件可只保存辅助附件，无需为它另造估值结果。

上述无决定变更的处理同样适用于纯消息／情绪补件，原基本面截止与新增附件时点分别保留；仅报价不得自动顺延原期限。重新采用从本次估值日起未来12个月的窗口属于模型假设变化：核对期末盈利口径、倍数与兑现路径，重算受影响结果并重新裁决，不要求无关输入或全部独立阶段重做。新版本通过`basis.supersedes`定位被替代范围，原报告、原底稿及前瞻登记的原窗口仍保留。关键旧引用缺失时，在`basis.note`点名精确缺失文件、受影响ID及不可继承的范围，不以今天的文件补旧依据；本次独立核验的材料另建采用记录。当前核心门槛仍未闭合时，`final_decision`保留未评级原因和空价带，不能沿用旧行动条件。

变化表的`仍有效 / 需重算 / 无法判断`针对具体旧输入／条件，不替代本次评级、模型状态或审查状态。受影响阶段和角色沿用同一精确`run-record`；没有取得更新就保留本次缺项。总览字段从本底稿的`target / basis / final_decision`及已保存读回的正式报告映射，规则见[SKILL.md](../SKILL.md#workspace-research-overview)，不生成第二个最终方案。

## 前瞻登记与复盘引用

发布前按[multi-agent-debate.md](multi-agent-debate.md#run-record-and-recovery)在原run-record最终采用栏收口一次，核同一报价、原期限/截止、比较符和等号、底稿/决定/结果ID与实际附件版本。当前说明直接写本次采用版，旧版沿革另列；生成/登记时间只填实际已观察时间，未知保留未知。冻结后实质错误仍另存修订，不能为少出版本隐去更正。未建立run-record的普通短答不为此新增独立审查流程，仍人工核对适用的引用与决定。

新完整研究发布时，按[research-review.md](research-review.md)从本底稿已采用的`final_decision`及其事实／假设／结果选择关键预期与主要失败路径。另存`thesis-review.md`，引用本底稿精确版本、`#/final_decision`及相关ID、原截止和预定窗口，不把未采纳敏感性结果改成承诺收益；缺预测或未评级如实登记，不补造数字。

复核结果放新版复盘附件，保留原判断；不向本共同外层新增必填字段，也不为挂接复盘回写已存底稿。重大新事实或计算错误沿既有更新规则另存受影响底稿／最终决定，再形成新报告；原复盘不是第二份评级或价带来源。

## 输入、单位与采用状态

所有记录的`id`在本底稿内唯一，建议用`F_`事实、`A_`假设、`D_`派生数、`SC_`情景、`SEN_`敏感性、`FD_`最终决定前缀。跨版本同一含义沿用ID；改变期间、实际/潜在或归属含义时另建ID，不偷偷更换旧ID含义。引用使用ID，不以数组下标表示业务身份。

`basis.report_ref / evidence_refs`使用`path / locator`文件引用；各记录内的`*_ref / *_refs`使用本底稿ID。`input_refs`可引用事实或已算派生数（如单位转换），`assumption_refs`引用假设，`result_refs`引用派生结果；假设的`evidence_refs`指向支撑记录，其原件仍由`verified_inputs.sources`定位。最终决定可引用缺失/冲突记录来说明阻断原因，但这些记录不能作为已采用数值参与计算。

`verified_inputs`每条保留：

| 字段 | 含义 |
|---|---|
| `id / name` | 稳定标识和指标名 |
| `value / unit` | 原值和明确单位，如CNY、亿元、股、亿股、CNY/share、%、ratio、倍；不能只写“金额” |
| `period` | 期间、时点或供应商交易时间；累计流量写起止，存量写时点，不用披露日代替报告期 |
| `scope` | 合并/母公司/归母、实际/潜在、累计/单季/存量；报价注明未复权、供应商和盘中/盘后 |
| `published_at / available_at` | 披露和可获得时间；未记录时为null并说明，不以下载时间补造 |
| `verification` | `status / verified_at / note`；注明原文核验范围、历史记录继承或具体冲突 |
| `adopted` | 本次是否采用为事实输入，布尔值；采用不能覆盖核验状态 |
| `sources` | 精确引用数组：`url / path / locator`，已有公告标识、PDF哈希则保留`document_id / sha256`；未知项为null，不计算或伪造旧核验时间 |
| `missing_reason` | 值为null时必填，说明缺什么及对模型/评级的影响；其他情况可省略 |

`verification.status`语义：

| 状态 | 是否可直接作为本次已核事实 |
|---|---|
| `verified` | 可；本次已核原文，或报价已核供应商时间及原始响应；须有核验记录 |
| `historical_review` | 仅记录历史曾核，不宣称本次重新核验；结构示例可沿历史说明采用，新评级仍须满足当前事实门槛 |
| `candidate` | 不可；采集候选或券商索引线索，`adopted=false` |
| `conflict` | 不可；冲突待解，`adopted=false`，列出冲突来源 |
| `missing` | 不可；`value=null`、`adopted=false`，保留缺口及解除所需原件 |

不要改写原核心包的`unverified`等状态。核验与采用记录属于本底稿；未来经营数据只能进入`assumptions`，不能升格为`verified_inputs`中的事实。

原始金额与股数保留原值和单位。需要换成亿元、亿股或小数比例时，只在`derived`转换一次，保存公式和原输入ID，后续引用该结果。运算比例用小数表示（32%=0.32，100%=1）；若原文为95.03%，事实保留95.03及`%`，派生数为0.9503及`ratio`。增长率、安全边际和价格空间也用小数，允许负值或超过1，不能截断到0—1。显示百分号只用于展示。

## 假设、计算及业务差异

决定性收入、持续归母率和倍数的`rationale / evidence_refs`分别说明：已核起点→驱动及有据范围→主要反证→最近可观察节点。收入对应销量/售价/结构/并表增量；利润率对应成本、良率、折旧、费用、税和归属；倍数对应可比业务、可持续增长/回报、资本约束与风险。不能复制同一段“景气向好”，也不能将季度年化当独立增长证据。披露不够时排除无据增量或给有据范围，不编分部贡献；决定性范围无法建立才按原未评级原因处理。

资本回报决定论点时，在现有`derived`中解释ROE的利润率、周转与杠杆归因。流量期间、主体及归母口径一致，资产/权益用可解释的期初期末平均或披露加权余额；重大增资/并表导致简单平均失真时说明限制或不算。加杠杆提高ROE不等于经营效率改善，不用期末余额冒充平均余额；负权益、缺可比期或不适用业务不硬算。PB须解释可持续ROE、权益成本、增长/分红和资本约束，行业边界见估值规则，不新增统一评分。

决定性争议沿`derived / sensitivity`给反向需求与联合压力，标清保持不变项、结果ID及判断翻转条件；反推是条件算式，不是市场共识。同一风险在盈利、倍数和折价中只计一次，敏感性不另造当前操作价带。虚构教学值不得进入真实研究的已核输入。

- `assumptions`条目保留`id / name / value / unit / period / scope / rationale / evidence_refs`。引用支撑事实，但不把假设写成事实；缺值保留null及原因。
- `derived`条目保留`id / name / value / unit / period / scope / formula / input_refs / assumption_refs`。`formula`是可人工复算的文字或算式，不是可执行表达式。保留中间精度，注明显示舍入；输入缺失时不能凭空给出可采纳结果。
- `scenarios`条目保留`id / label / method / input_refs / assumption_refs / result_refs / limitations`。低/基准/高均引用同一采用基础；替代分母明确对应事件及净款/费用/盈利处理。结果放在`derived`，本区引用，避免多处独立计算。
- `sensitivity`条目保留`id / question / changed_assumption_refs / held_constant_refs / result_refs / decision_effect`，说明哪些驱动变了、其余沿用什么，以及现价判断是否变化。敏感性不是新价带，不捏造情景概率。

外层不强迫不同公司使用同一经营模型：

| 方法/事项 | 必须保留的差异 |
|---|---|
| PE | 量价、毛利/费用/税/归母或持续归母率等驱动；明确历史、TTM、预测或正常化盈利 |
| PB | 同期同口径归母权益和实际股本；分红/回购/交易仅桥接报表日后增量，不用合并净资产替代归母权益 |
| SOTP/现金流 | 各分部或现金流的期间、归属、净债务/现金及义务处理；统一到股权价值后再除股数，避免重复扣债 |
| 股本 | 历史基准→已完成增减及登记/生效时间→已核实际股数→潜在摊薄。EPS加权平均股数、发行上限和潜在绿鞋都不能冒充当前实际股数 |
| 交易归属 | 法律持股、会计归属、并表期间、融资费用、回购/担保义务与本金分开；只按个股必要事项记录，不额外造通用交易模板 |

## 按需财务核查与采用

九个新增财务候选字段及来源表见[data-source-policy.md](data-source-policy.md#financial-statement-candidates)。核心包仍保留`unverified`，本底稿将未核数字记为`candidate / adopted=false`；读到原件、核清期间／单位／主体后再记录本次核验和采用。缺字段时保留`missing`、null及影响，不补零；上游明确给出的数值零与缺失分开，投资收益、公允价值变动收益及利润可为负。

以下表只记录影响本次判断的事项，可放在报告第4节或既有人工说明中，与精确底稿版本互引；不新增共同外层必填区块。金额、事实、假设和计算仍分别进入`verified_inputs / assumptions / derived`，表内引用其ID；独立说明附件由`basis.evidence_refs`记录精确版本和定位。未公开或无法核清的事项写缺口及影响，不要求逐笔填满。

### 资金与重要付款核查表

| 付款主体／币种 | 余额日期与现金输入ID | 受限／可用金额及原文依据（页码／输入ID） | 重大用途、未付金额与付款窗口（输入ID） | 已落实可提款融资、条件及期限（输入ID） | 经营现金假设与期间（假设ID） | 未知／未覆盖部分及判断影响（缺口／结果ID） |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

- 集团合并货币资金不等于母公司或特定子公司的可用现金。核清付款主体、余额日、币种、受限条件与跨主体调拨依据；未知受限资金不能默认零。仅有集团余额时，保留逐主体可用性的缺口，不宣称资金覆盖。
- 授信额度、融资意向或股东支持承诺不能写成现金到账。拟计入融资覆盖时，核查已落实、尚未使用且可在付款窗口提款的金额、条件和期限；已经到账并进入期初余额的净款不得再加。未来经营现金与续贷条件放`assumptions`，不能作为已核余额，预测期间从余额日衔接，已实现部分不重复相加。
- 按同一余额日和未来窗口核对债务本金、利息及交易／设备等付款。本金不作为利润费用，财务费用已进入盈利或现金流的处理位置须明确；估值扣债与资金用途中的本金、已含利息不得重复扣减。同一义务已列应付款、资本开支或其他用途时，只计一次，不把上述余额全部盲目相加。
- 分红、回购、交易及融资只桥接报表日后尚未入账的增量；已入余额的收支不再加扣。融资净款与费用、未付对价、已付购建长期资产现金及未来承诺分别记录，不能把全额计划资本开支再扣一次。

### 非经常、归属与股本原文采用记录

| 按需事项 | 原文须核清的内容 | 底稿记录与边界 |
|---|---|---|
| 非经常损益／非主营收益 | 扣非与非经常明细、投资及公允价值变动的性质、税前／税后及少数股东影响、适用期间 | 已核金额及原页进事实，正常化调整进派生数、持续性判断进假设；投资收益不自动全为一次性，合并税前收益不能直接从税后归母或扣非利润再次扣除。 |
| 少数权益／并表及重要交易 | 法律持股与会计归属、并表起止及利润归属；对价总额／已付／未付、付款窗口、回购／担保等条件义务及触发状态 | 引用原件及事实ID，经营到持续归母的桥接保留公式、期间和假设；不能用一个持股比例替代会计处理，子公司利润不能全部归母。 |
| 股本事件 | 报表基准股数→增减事件与状态→登记／生效日期→当前实际股数；未完成潜在摊薄及对应净款／费用／盈利 | 沿既有股本桥接记录事实与派生ID；公告额度、基本EPS加权股数、未完成发行不作实际股数，已入账现金／权益不再加扣。 |

上述未自动取得的内容仍由研究者从原始披露手工补核，不增加自动接口。重要未知可能构成事实核验缺口，但一般披露不足或资金缺口假设本身不证明造假、违约，也不能因未发现违约就宣称已证明偿债能力。

### 可解释的财务讨论

- 优先复用本底稿已采用输入与计算ID，说明“哪项、哪个期间、如何变化、为何值得查、尚缺什么”，不生成综合财务分数。仅比较同口径、可比期间；累计流量写清年初至期末，单季仅在同年同口径累计数可比时相减，并在`derived`保留两端输入。存量用期末日期，不把余额差当成本期收入或现金流。
- 营业收入与营业成本范围可比、收入为正时，才计算毛利率；不以营业总成本替代营业成本。现金转换须核对利润与CFO的主体和期间：合并CFO不能与归母利润混称同口径转换率，缺合并净利润时可并列讨论并说明口径差异，不反推或自动补字段。
- 应收／存货结合可比期末余额、收入／成本和季节性解释，必要时手工核账龄、合同资产／票据、减值或并表变动。缺少适用期间、分母不为正或口径不可比时，不强算增长率、转换率或周转率，保留原值与变化额及不可计算原因；增长快不直接升级为造假。
- 只有同期间、同主体的已采用CFO与`capex_cash_paid`齐备时，才在`derived`计算并标注“简化CFO－购建长期资产现金”；缺任一项则留缺口。购建现金不等于投资现金流净额，不用其替代；该差额未完整处理税、融资、并购或其他必要调整，不能称完整FCFF或直接证明可分配现金、偿债能力。

## 最终条件与缺口

`final_decision`记录已采纳决定，并以`input_refs / assumption_refs / result_refs`指向上述同一基础；Agent提议和未采纳旧边界保留在各自历史来源，不混入本区。期限、财年和截止从同一`basis`读取；旧方案引用统一用`basis.supersedes`，不再维护第二份。外部引用须同时给出底稿精确文件、`#/final_decision`定位及`id`，不能仅用跨版本可能相同的ID识别方案。

| 字段 | 含义 |
|---|---|
| `id / rating / unrated_reason` | 稳定ID、现有五档评级或`数据不足，暂不评级`；未评级原因为`type / reason`及适用的`input_ref`，type沿用`事实缺口 / 模型未完成（研究未完成） / 模型无法可靠界定`，非适用时原因为null |
| `confidence / confidence_reason` | `高 / 中 / 低`及决定性原因，不是收益概率 |
| `new_money_status` | `仅观察 / 条件满足后复核 / 条件已满足`，不推定个人账户适配；未知个人预算单列于`user_constraints` |
| `reference_quote_ref` | 与`basis.reference_quote_ref`相同，指向报价输入ID；输入含价格、CNY/share、供应商交易时间、阶段及原始来源，缺失值保留null及原因，不补造现价；期限、财年由`basis`提供 |
| `buy_range / hold_range` | 有效时各含`lower_ref / upper_ref / lower_inclusive / upper_inclusive / unit`，端点引用`derived`，写清等号；不适用时为null |
| `price_ceiling_ref / reassess` | 入场上限引用；重评项记录价格结果引用及比较符，或具体事件，不造机械卖出价 |
| `necessary_conditions / watch_items / user_constraints` | 必要条件注明依据及当前满足/未满足/未知状态，普通观察和未知个人预算分别记录；未知账户信息不填默认比例 |
| `hard_constraints` | 每项写`id / evidence_refs / impact / release_condition`；无约束为`[]`。事实核验门槛未闭合可列为阻断，但须明示缺失核验，不能伪装成已证实经营/偿债风险事件 |
| `invalidation_events / next_update` | 事件触发、最迟复核日期及期限届满要求；不等于已创建自动任务 |
| `input_refs / assumption_refs / result_refs` | 最终判断实际采用的输入、假设及计算ID；不能只引用一个没有依据的评级 |

`买入/增持/持有`的数字价带、带内关系与生效条件遵守现有评级规则；`减持/回避`为暂不买入，`buy_range / hold_range / price_ceiling_ref`均为null，只保留有据重评价位或事件。未评级时同样保留空价带及空入场上限，不把情景值写成数字交易/减持区间。

`买入/增持`须现价在有效买入区且研究必要条件满足，`new_money_status=条件已满足`；个人预算未知独立披露，不冒充研究硬阻断。`仅观察 / 条件满足后复核`均不授权当前试仓/加仓。价带端点与入场上限引用已采用的`derived`结果；相邻行动共享端点时只由一侧包含等号，显示舍入不得改变已采纳边界及比较符。新资金上限不能高于有效买入区上沿。

**模型完成但事实未闭合：** 可保留明确假设分母下的情景及敏感性，`basis.model_status=completed`；当前实际股本输入仍为`missing`、null且未采用。`final_decision.rating=数据不足，暂不评级`、原因为事实缺口、新资金仅观察、价带及上限null。补齐原文后仍须结合届时报价和模型重评，不自动恢复旧价带。

交付时人工读回引用的实际文件、单位期间、核验状态、转换、结果ID、最终条件和报告映射；历史继承说明不等于重新核验。原文核验、输入采用、计算/敏感性、评级裁决及跨文档对齐仍由研究者人工完成；附件分类只按现有读取分支解释，不验证上述内容，首次实际使用和运行兼容仍待用户验收。
