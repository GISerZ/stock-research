# A 股情绪证据与跨市场参照

情绪研究按“近期消息 → 市场叙事 → 预期变化 → 心理假设 → 量价验证”展开，数值快照与主动浏览的定性证据共同使用。热度描述关注程度，不直接等于看多、看空或实际资金方向。

## 采集顺序

来源请求现由共享 SourceRuntime 顺序执行，失败保留 `rate_limited / malformed / source_failure` 及错误分类、重试与冷却记录；空榜／空表不自动解释为 no_record。只有有效非空榜单明确查无目标时，才写覆盖外 no_record。东财当前榜的上述失败可触发独立同花顺观察，东财历史与雪球字段仍保留原始状态；候选成功不改变其五日完整性。个股 complete 还要求最新完整市场日可用、三个专题池五日有效覆盖和同口径五日热度齐全，旧日不可补采的广度继续单列缺口。诊断失败先读 JSON，再用 `scripts/check_source_health.py --output-dir .` 看本地来源历史；不要循环重启采集规避冷却。

在单股深度研究中，先运行核心证据采集器，再运行 `scripts/collect_sentiment.py --code CODE --output-dir WORKSPACE`。单股命令读取已保存的市场日快照，在接口近期范围内补采缺失的涨跌停专题池，并采集热度、讨论热榜与近期新闻候选；过去日期的乐咕市场广度始终记为不可补采。可用 `--social-review-file` 和 `--cross-market-file` 加入研究者核验的原文与国际参照。记录两个证据包的精确路径，再冻结同一组文件给多头、空头和三方风控 Agent。新闻与帖子中的重大事实仍须回到官方披露核对。

每日市场任务采集乐咕沪深两市市场广度和东财涨停、跌停、炸板三个专题池。北京时间 18:00 和 20:00 的任务由本机 Windows 任务计划程序触发；主机须开机、当前用户已登录、Python 环境及数据源可用。查看 `research/evidence/sentiment/schedule.log`、任务计划程序的上次运行结果和 `research/evidence/sentiment/market/` 当日 JSON 中的 `issues`；导入或启动阶段失败时可能只有日志而没有 JSON。缺失的乐咕当日统计不能用次日数据倒填。技能不会在没有运行会话时自行启动。

18:00／20:00是完成日采集与补缺，不保证两次不同的新鲜快照。市场CLI先查当日已有`complete`：存在即打印原精确版本的绝对路径并退出，通常不会在20:00重新请求来源或核查源端修订。已有`partial`／缺失时才进入采集；定时覆盖检查仍另行执行。本批不增加刷新参数、不改调度或回写旧快照。

定时脚本在采集后运行只读的 `scripts/check_sentiment_coverage.py --output-dir WORKSPACE`，把最近完整交易日的选用快照版本、状态和近五日逐字段有效点与缺日追加到同一 `schedule.log`。健康命令以新浪交易日历确定日期；日历不可用显示 `calendar_unavailable`，不按工作日猜测。退出码 0 为最近交易日完整，1 为最近交易日缺失或部分完成，2 为日历或读取错误。过去交易日无法补采的乐咕广度只作为覆盖缺口，不让已完整的最近交易日永久报警。

手动采集当天已完成交易日的市场快照，在工作区根目录打开 PowerShell，运行：

```powershell
$stockSkill = Join-Path $env:USERPROFILE '.codex\skills\stock-research'
python (Join-Path $stockSkill 'scripts\collect_sentiment.py') --market --output-dir .
```

在北京时间交易日 15:00 后运行；如 `python` 不是定时任务使用的环境，换成安装定时任务时指定的 Python 可执行文件。命令同步打印快照绝对路径；若采集不完整，会保存部分诊断快照、在标准错误中列出缺口并返回非零退出码。已有完整同日快照时直接返回其路径。非交易日不生成市场快照。手动命令和定时任务共用 `research/evidence/sentiment/market/`，不会采集海外参照。

## 近期消息、叙事与投资者心理

单股深度研究须完成本节；情绪专题问答按问题裁剪，短答仍按 `SKILL.md` 的保存规则。默认检索最近两周消息，对关键叙事追溯本次检索能核实的最早来源；不是声称找到了全网首次发布。写明检索起止、带时区的研究截止时间和拟观察的短期时间范围，默认未来数日至数周并标作研究假设，不替代基本面研究的持有期限。

### 主动检索范围

| 层次 | 检索内容与选择依据 |
|---|---|
| 公司 | 代码、简称、曾用名或英文名；公告、IR、经营事件、监管及重要媒体原文。 |
| 国内板块与产业链 | 产品、板块、同行、客户、供应商及政策关键词；寻找独立的需求、供给、价格、替代技术和市场讨论证据，记录实际传导关系。 |
| 海外相关信息 | 用英文名、产品名及相关客户／竞争对手名检索当地原始披露、政策和行业消息；区分直接经营影响、竞争替代、估值参照与仅有主题联想。同一海外事件可能利好客户却利空供应商，须给反例。 |
| 投资者讨论 | 在可访问平台兼顾近期、热门及相反观点，记录平台、时间范围、排序／检索方法、抽样数量和直达原文；去除同文转载、明显推广与无关内容。未找到相反观点不等于市场没有分歧。 |

保存实际使用的检索词、语言、时间范围、检索时刻、原文链接与覆盖缺口。海外无重要关联时写筛选理由；无法访问、仅见搜索摘要与核查后未发现重要新增消息分别说明，不推断为“没有消息”。重要内容打开原文；付费墙、登录或删除导致不可核时保留限制，不把摘要当已读原文。按来源首发和事件内容归并转载，报道条数不当作独立利好数量或传播人数。

由研究者自行完成可行的浏览与帖子审核，审核文件是研究产物，不将其转成用户必须手工提供的前置任务。帖子中的公司事实仍回到官方原文核验；帖子原文只能证明该作者在该时点表达了什么。小样本、热门排序和搜索排序都不能估计全体投资者的看多比例；券商公开观点不能证明机构实际交易。

### 关键消息的预期变化卡

每个足以影响判断的事件赋予稳定 ID，保留以下内容；同一事件的转载共用一张卡：

- **来源与时间：** 关联公司／板块、国内或海外、原文标题及 URL、事件发生时间、发布时间、研究时可获得时间、检索时间和核验状态。时间不可核时写缺口，不建立其先于价格的因果顺序。
- **信息增量：** 已核事实、媒体转述、观点或未证传闻；首次核得的消息、后续实质更新或旧闻重炒。重大事实遵守原始披露核验要求。
- **原预期 → 新信息：** 引用消息发布前可得的公司指引、已核预测或带日期观点作为参照；样本观点不称全市场共识。参照不足写“预期差无法确认”，不直接称超预期／低于预期。
- **叙事与传导：** 市场样本在讲什么故事，如何影响该公司的需求、成本、利润、估值或短期关注；列出竞争叙事和最强反证，不把尚未兑现的故事写成经营事实。
- **反馈与后续：** 同期个股、选定板块／同行的量价反应，是否已提前反应的证据及其他解释；下一核查事件和可观察的失效条件。

海外定性新闻同样记录在消息卡中，不为满足 `--cross-market-file` 的数值字段而虚构价格、单位或五日序列；涉及海外行情的量化结论仍遵守下文国际参照契约。

### 用行为证据约束心理解释

心理分析写成“观察 → 心理假设 → 替代解释 → 反证”，不是断言已知道投资者动机。按实际证据选择，不必逐项套用：

| 心理假设 | 可核观察线索 | 替代解释或反证方向 |
|---|---|---|
| 从众、害怕踏空 | 样本讨论由业务争议转向追涨，同一叙事被反复引用；再看板块和价格是否响应。 | 推广、平台排序或少数账号重复发声；不能据此认定全市场拥挤。 |
| 锚定、回本与损失厌恶 | 样本反复围绕持仓成本、前高和整数价位解释行为。 | 个人表达不是该价位真实筹码或卖单，不能直接推出必有抛压。 |
| 确认偏误、线性外推 | 样本放大有利消息、忽视反证，或把单季／单次涨价延伸为长期趋势。 | 新事实也可能足以支持上修；主动查找最强相反原文，研究者自身同样接受反证。 |
| 恐慌、失望或利好兑现 | 负面表达、预期落空与消息后的量价反应有时间对应。 | 市场共振、流动性或真实经营恶化；利空后企稳不等于出清完成，利好后回落不证明出货。 |

一致乐观不自动见顶，悲观不自动见底；不从成交量、筹码模型或帖子推断主力意图、真实账户身份或“洗盘／出货”。证据不足时保留多个解释，不用心理故事填补事实缺口。

### 量价与板块反馈

先按业务确定板块／同行及比较理由，再看其表现，避免只挑支持结论的上涨样本。对照消息可获得前后的个股及参照涨跌、成交与扩散情况；注明来源、窗口和价格基准，跨除权日用可比的复权收益序列，当前评级报价仍用未复权价。盘中只比同一已完成时段，不能用盘中成交与完整日成交直接相除。跨市场先核可获得时间，海外晚间消息不能解释此前 A 股收盘。

说明是新增信息领先、价格提前变化、旧闻再传播还是先后不明；共同涨跌和事件后的相关性不认证因果，保留市场整体变化等解释。没有可比行情时明确“价格验证不足”；上涨本身不能证明故事真实，也不能精确量化已经计价多少。保留原有五日数值覆盖要求；定性检索窗口不补成完整五日指标。

### 输出、归档与复核

情绪小结写明：主导叙事及竞争解释、增量消息与原预期依据、样本心理线索、量价验证、情绪置信度及决定性缺口、失效条件与下一观察时间／事件。事实、样本观点和模型推断分开。阶段词如“升温／分歧／降温”须给证据，支持不足写“无法判断”；不输出未经校准的总分、胜率或情景概率。

深度研究将检索记录、消息卡、帖子审核依据和心理推理保存在 `research/evidence/manual/YYYY-MM-DD-CODE/narrative-review.md`，同日更新用 `narrative-review-v2.md` 等新版本。报告与冻结简报引用实际使用的精确版本及截止时间；附件内用正确相对路径引用快照，原文用直达 URL。检索失败也保存实际范围和限制，不伪造消息卡。复研对照当时已写的假设与失效条件，不用后见信息改写旧判断。

附件独立于情绪 JSON，保持现有 schema、命令及历史文件不变。已核帖子可按下节格式另存审核 JSON；量化海外参照仍用既有格式。若未导入所引快照，报告分别说明附件的实际审核状态和快照原有 `not_reviewed / partial`，不因附件新增而宣称快照已完整，也不为更新定性判断反复启动采集。

短期情绪置信度与基本面研究置信度分别说明。缺少帖子或板块反馈只限制相应结论，不自动阻断已满足条件的基本面评级；情绪热烈或悲观均不单独改变评级、价格上限或个人仓位。新发现的已核经营事实可按原估值流程更新模型与唯一最终方案。

## 国内指标口径

### 按问题阅读辅助覆盖

新个股CLI在帖子及跨市场文件处理后、保存前附加可选`analysis_coverage`，逐项说明`heat_history`的有效日／所需5日、`market_fields`七字段的有效日与缺日、`news_candidates.saved_count`及`candidates_only`、帖子原`status`和海外原`selection_status`。它只复述保存内容；仍须读`source_results`、原五日记录和审阅附件，不据此升级`partial`或生成评级。

`window_status=unavailable`时没有已核五交易日窗口，日数／缺日为`null`，不按工作日猜日期；`missing_fields`标记旧包／失败包缺少的输入。已记录空列表在窗口已知时只表示零个保存的有效日／候选，缺字段的计数为`null`。市场按各日原观察`ok`且非null计数，保存的数值零仍是有效观察；不要求整日`complete`才承认其中可用字段，也不把计数解释为原始事实已核。

| 实际覆盖 | 可以支持／需要披露 |
|---|---|
| 东财热度五日可用，广度部分缺日或雪球失败 | 可描述同口径关注变化；广度只列可用日，讨论方向无法由榜单失败推断。 |
| 有新闻候选，尚未审原文 | 只说明已保存线索数；重大事实、预期差及消息先后仍待核。零候选不证明没有消息。 |
| 帖子`not_reviewed / unverifiable / no_posts` | 分别表示未审、不可核、按所述方法无可核样本；均不能估计总体看多比例或推成看空。 |
| 海外`none_material / not_reviewed / unavailable / selected` | 分别是有理由的无重要参照、未筛选、不可用、已有选中参照；selected仍需逐条读传导／时间／五日限制。 |
| 日历失败 | 保留失败诊断、null交易日和原退出码，摘要不成为完整日证据。 |

报告按“可支持的判断｜缺口｜对核心模型的具体影响”表达。短期情绪置信度与基本面置信度分开；辅助失败不自动转成暂不评级，核心原文／实际股本／带时间戳报价缺口仍遵守硬门槛。旧快照无摘要时从原字段人工说明；后来新增审阅附件不改变旧快照的`not_reviewed / partial`或旧摘要。

| 指标 | 读法与限制 |
|---|---|
| 市场广度 | 乐咕源称“沪深两市”；保存上涨、下跌、平盘、停牌家数和来源统计时间。统计时间早于 15:00 或日期不符即记 `stale`。不要称为全 A 股，也不要直接用于北交所标的的同范围比较。 |
| 涨停／跌停／炸板 | 东财专题池排除 ST 与科创板；涨停池还排除未中断连续一字涨停的新股，不能称为全 A 股家数。三个池子分别计数；涨停池的“炸板次数”与炸板股池家数不同。当前固定的 AKShare 1.18.97 跌停池实现仅在明确空 `pool` 时返回空表，可记零；涨停与炸板池的空表不能证明有效零，当前适配器记 `malformed` 和 `null`，历史原状态保留。只在同日、同范围、互斥口径核实后才讨论比率。 |
| 个股热度 | 历史排名按 A 股交易日历过滤非交易日；名次数字越小越热。当前前 100 榜仅交叉核对，榜外是覆盖外，不是排名零。历史五日不足则只列可用日与缺口。 |
| 同花顺当前热榜候选 | 东财当前前100接口 `source_failure / rate_limited / malformed / stale` 时，请求同花顺 A 股 `day / normal` 当前榜。`ths_current_heat_rank` 带返回榜单大小、范围、来源 URL 和抓取时刻，`observation_time_basis=retrieval_only`；有效非空榜中无目标才记 `no_record`，空榜／结构异常记 `malformed`，请求失败按运行时分类保留。它不是东财名次、雪球讨论名次或东财五日历史；不同平台名次不能相减。 |
| 讨论热榜 | 雪球“最热门”榜保留原始“关注”字段与完整返回列表中的位置；该字段不推断为帖子数量、看多比例或全体投资者情绪。 |
| 新闻与帖子 | 东财新闻是最近有限条候选，五日覆盖不保证；帖子须有直达链接、目标代码、发布时间、摘要和抽样方法。帖子小样本不推断总体比例。盘后新增消息另列，不能混入该日收盘统计。 |

市场日 JSON 位于 `research/evidence/sentiment/market/YYYY-MM-DD[-vN].json`，单股 JSON 位于 `research/evidence/sentiment/stock/YYYY-MM-DD-CODE[-vN].json`。同日仅在来源值或状态变化时建立新版本；报告写使用的精确路径。`ok / no_record / source_failure / stale / not_supported` 分别表示可用、无可核记录、采集失败、时间不符、来源不覆盖。榜单覆盖与收盘最终性另列，`null` 不当作零。

乐咕广度带来源统计时间；东财池子和当前热榜未提供可核的来源观测时刻时，`observed_at` 仅记录抓取时刻，并以 `observation_time_basis=retrieval_only` 明示，不能当作提供方确认的收盘时间。

同花顺候选即使取得 `ok`，东财原始失败状态与个股快照 `partial` 仍保留。它只辅助解释当前关注度，不能替代独立的可核帖子审核，也不能放宽公告、股本、报价与评级的核验门槛。

最近完整交易日以研究时已经结束的 A 股交易日为准。近五日须有五个同口径有效点，逐日列出后再计算首末变化。热度排名变化应写首末排名和方向。任何缺日、来源变更或范围变化都不插值、不补造完整五日趋势。
单股快照的 `five_day_coverage` 按指标保存有效交易日数；`market_five_days` 每日保留所选市场版本、来源状态、有效字段与缺口，报告需逐项阅读，不能用一个总点数替代各指标的覆盖。

## 人工帖子审核文件

`--social-review-file` 为 UTF-8 JSON，`status` 取 `reviewed` 或 `no_posts`；还须有 `sampled_at`（带时区）、`selection_method` 和 `posts`。每条帖子含 `code`、`published_at`、`source_url`、`summary`。`no_posts` 表示按所写抽样方法核查后无可核帖子，不代表社交平台没有讨论。未提供文件显示 `not_reviewed`；字段或链接不可核验显示 `unverifiable`。例如：

```json
{"status":"reviewed","sampled_at":"2026-09-29T16:00:00+08:00","selection_method":"公开搜索结果中按发布时间选取与目标直接相关的帖子","posts":[{"code":"600206","published_at":"2026-09-29T14:00:00+08:00","source_url":"https://example.com/direct-post","summary":"帖子讨论半导体材料订单，未核实订单事实"}]}
```

示例 URL 仅说明字段格式，实际研究须填写可打开的原文。

## 国际科技与宏观参照

研究者先写明目标公司的业务、客户、成本、估值或融资传导路径，再选择少量参照；不固定展示整套全球面板。半导体材料企业优先找产品或客户链条可比的材料与晶圆企业，不能因为海外公司也属科技板块就认定可比。

1. 海外同业与 SOX／NDX：保存同业可比点和差异，比较相同海外交易时段的自身及相对板块涨跌。共同涨跌仅显示风险偏好或关联线索，不证明 A 股公司业绩同步。
2. VXN／VIX 与 Cboe 认沽／认购比：波动率衡量期权隐含波动，不能独立给出方向。五日变化分别以指数点和比值点表示；认沽／认购比须标明总市场、股票、指数或 ETP 范围，不能冒充目标股期权情绪。
3. 美国名义／实际国债收益率、FedWatch、信用利差：只在贴现率、融资或汇率路径明确时使用。收益率与信用利差变化用基点；FedWatch 保留指定会议、结果定义与期货隐含概率，同一会议同一结果的变化才用百分点比较。实际政策决定以美联储原文为准。
4. 原油、其他商品与 USD/CNH 或 USD/CNY：只在有收入、采购或成本暴露时使用，保留现货／期货、合约或品级、币种、单位和来源延迟。油价对生产商和耗油企业的影响可能相反。
5. ETF 份额或资金变化仅在原始数据、发布时间和统计范围可靠时补充。财报、AI 资本开支、晶圆厂营收和芯片价格属于需求或供给证据，可解释预期差，但不标成纯情绪指标。

`--cross-market-file` 为研究者选取的 UTF-8 JSON。顶层含 `selection_status`（`selected / none_material / unavailable`）、`research_as_of`、`selection_reason`、`references`。未提供文件显示 `not_reviewed`。每个选中参照须有 `kind`、`instrument`、`selection_reason`、`transmission`、`countercase`、`value`、`unit`、`basis`、`market`、`market_timezone`、`currency`、`session`、`source_name`、`source_url`，以及带偏移的 `observed_at`、`published_at`、`available_at`、`retrieved_at`。`final_close` 须有 `session_close_at`；美股未收盘时可用已完成时段，盘中值须明确标为 `intraday`。每个海外市场各按自己的交易日历。五日计算还需 `expected_trade_dates` 五日列表，以及 `calendar_evidence`：`market`、`market_timezone`、官方或可核的日历 `source_url`、`verified_at`、同样的 `dates`、`verification="analyst_checked"`。主研究者须打开该来源核对交易日；代码只检查清单一致性，结果标为 `complete_manual_calendar_review`。`history` 每点须有交易日、值、同参照的标的／单位／口径／币种／交易时段／来源名称、直达 URL，以及观测／公布／可获得时间；最终点须与当前值和观察时间一致。海外同业额外写 `comparability`、`difference`；FedWatch 写 `meeting_date`、`outcome`，五日各点保持相同定义；商品写 `price_type`、`contract_or_grade`、`publication_lag`。选择理由、反例、日历或时间证据不足的参照保留缺口，不进入五日结论。

国际参照只辅助解释拥挤度、短期预期差和风险条件；不得单独决定评级、价格区间或仓位。最新重大披露、股本口径或带时间戳现价未核实时，继续写 `数据不足，暂不评级`，不报数字交易区间或计划仓位。
